# Security policy

## Reporting a vulnerability

Please report a suspected vulnerability in private, not in a public
issue, pull request or discussion.

Use GitHub's private vulnerability reporting for this repository: the
**Report a vulnerability** button under the **Security** tab. If the
button is not there, open an issue that only asks for a private
contact, without any detail of the problem.

A useful report says which version or commit is affected, what input
triggers the problem and what happens.

## Supported versions

Fixes are made on the latest release.
